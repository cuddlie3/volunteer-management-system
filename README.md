# Qoldau — Система управления волонтёрами

Веб-приложение для управления волонтёрами спортивных и массовых мероприятий. Система предназначена для координаторов и ответственных за организацию работы волонтёров.

## О проекте

Qoldau позволяет централизованно управлять информацией о волонтёрах, распределять их по зонам и сменам, фиксировать посещаемость и вести учёт отработанных часов.

### Проблема

Информация о волонтёрах, расписании смен, распределении по зонам и отработанных часах часто хранится в мессенджерах и электронных таблицах. Это может приводить к потере данных, ошибкам при распределении волонтёров и дополнительным затратам времени на подсчёт отработанных часов.

**Цель проекта** — объединить основные процессы управления волонтёрами в одной системе.

## Для кого предназначена система

- Координаторы волонтёров
- Сотрудники, отвечающие за организацию волонтёров на мероприятиях

## Основные возможности

- Ведение записей о волонтёрах
- Управление зонами мероприятия и координаторами
- Создание и планирование смен
- Назначение волонтёров на смены
- Учёт посещаемости
- Рассмотрение заявок на регистрацию волонтёров
- Интеграция с Telegram-ботом

*Функции реализуются и тестируются постепенно. Не все возможности завершены.*

## Используемые технологии

- **Язык программирования:** Python
- **Веб-фреймворк:** Django
- **База данных:** SQLite для разработки
- **Telegram-бот:** Python Telegram Bot
- **Конфигурация:** переменные окружения

## Установка и запуск

### 1. Клонирование репозитория

```powershell
git clone https://github.com/cuddlie3/volunteer-management-system.git
cd volunteer-management-system
```

### 2. Создание виртуального окружения

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. Установка зависимостей

```powershell
python -m pip install django python-telegram-bot python-dotenv
```




### 5. Применение миграций

```powershell
python manage.py migrate
```

### 6. Создание администратора

```powershell
python manage.py createsuperuser
```

### 7. Запуск веб-приложения

```powershell
python manage.py runserver
```

После запуска откройте административную панель:

http://127.0.0.1:8000/admin/

### 8. Запуск Telegram-бота

Откройте второй терминал, активируйте виртуальное окружение и выполните:

```powershell
python bot.py
```

Для запуска необходим действительный токен в файле `.env`. Полноценное взаимодействие бота с базой данных Django ещё находится в разработке.
