# volunteer-management-system

Веб-приложение для координаторов волонтёров спортивных и массовых мероприятий. Система позволяет регистрировать волонтёров, распределять их по зонам и сменам, фиксировать присутствие и вести учёт отработанных часов.

**Для кого:** координаторы и ответственные за работу волонтёров на мероприятии.

**Проблема:** сейчас информация о волонтёрах, сменах, распределении по зонам и отработанных часах ведётся в мессенджерах и таблицах. Из-за этого информация может теряться, возникают ошибки при распределении, а формирование итогового количества отработанных часов занимает дополнительное время.

**Заказчик:** координатор волонтёров спортивного мероприятия.
